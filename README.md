## Topics Covered

- C# Fundamentals
- Object-Oriented Programming
- Collections & Generics
- LINQ
- Delegates
- Async/Await
- Exception Handling

## Purpose

This repository contains practical examples and exercises
created while learning and strengthening C# and .NET skills.
